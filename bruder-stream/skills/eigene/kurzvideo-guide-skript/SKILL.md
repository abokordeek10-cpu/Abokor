# Kurzvideo-Guide-Skript

## Format
Eine Frage, die viele Spieler haben → **Antwort ohne Umwege**. Das Gegenteil von 20-Minuten-Guides.

## Aufbau
1. **Hook (0–3 s):** Ergebnis oder Versprechen. „So bekommst du in 5 Minuten 50.000 $.“
2. **Beweis (3–8 s):** kurz zeigen, dass es klappt (Kontostand, Ort, Auto).
3. **Schritte (Hauptteil):** 3–5 Schritte, jeder ein Satz, jeder mit Bildhinweis.
4. **Bonus-Tipp:** ein kleiner Extra-Tipp, der den Clip länger anschauen lässt.
5. **Loop/Ende:** Frage an die Zuschauer oder Übergang zurück zum Anfang. Optional: „Mehr live auf Twitch.“

## Länge
- TikTok-Version: **61–90 Sekunden** (ca. 150–220 Wörter Sprechtext)
- Shorts/Reels-Version: **30–60 Sekunden** (ca. 75–150 Wörter)

## Ausgabe
```
TITEL: …
HOOK-TEXT IM BILD: … (max. 6 Wörter)

SKRIPT (zum Einsprechen):
[0–3 s] …
[3–8 s] …
Schritt 1: … (Bild: …)
...
Bonus: …
Ende: …

BILDUNTERSCHRIFT: …
HASHTAGS: #gta6 #gta6deutsch …
QUELLEN / SELBST GETESTET: …
```

## Regeln
- Nur Methoden und Orte, die **selbst im Spiel getestet** oder mit **Quelle** belegt sind. Sonst als „ungetestet“ markieren.
- Einfache Sprache, Du-Form, keine Füllwörter.
- Keine Story-Spoiler. Die Regeln aus `hook-und-clip-regeln` gelten zusätzlich.
