# Abora „Kein Anruf verloren“ – auf einer Seite

**Problem:** Handwerker stehen auf der Baustelle und verpassen Anrufe. Ein Teil der Anrufer ruft nie wieder an.
**Kunde:** kleine Handwerksbetriebe ohne Bürokraft, zuerst Rhein-Neckar.
**Angebot:** Jeder verpasste Anrufer bekommt sofort eine SMS/WhatsApp in deinem Namen; seine Antwort kommt als Zusammenfassung aufs Handy, Notfälle zuerst. Ausgebucht-Modus. Festnetz-Ansage. Keine App, Nummer bleibt.
**Preis:** 79 € / Monat, keine Einrichtung, monatlich kündbar. Vorher kostenloser 14-Tage-Anruf-Check.

| Zahl | Wert |
|---|---|
| Beitrag je Kunde/Monat (heute / günstige Nummer) | 20 € / ca. 55 € |
| Gewinnschwelle | 5 Kunden (heute) / 2 Kunden (günstig) |
| Jahr 1 Gewinn (16 Kunden im Monat 12) | ca. 468 € / ca. 3.344 € |
| Startkapital nötig | ca. 730 € |

**Belege:** Käufer-Panel 0/20 Kauf, aber ca. 15/20 würden den Gratis-Check machen. Konkurrenz 10–119 €/Monat, keine bietet „eingerichtet + ohne Sprach-KI + fester Preis + regional“. Echter Test steht aus.
**Wofür das Geld:** Steuerberater, Telefonnummern, Flyer.
**Bitte:** Kein Geld. Gesucht: 3 Handwerksbetriebe in Rhein-Neckar für einen kostenlosen Anruf-Check.
